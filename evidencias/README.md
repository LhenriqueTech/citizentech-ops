# Evidências técnicas

Esta pasta recebe as evidências geradas automaticamente por:

```bash
sudo ./provision.sh validate
```

Cada execução cria uma subpasta `AAAAMMDD-HHMMSS/` com o checklist (`00-checklist.txt`) e as saídas de rede, DNS, firewall, serviços, aplicação, monitoramento, alertas e auditoria.
